<h1> Cybersecurity HomeLab</h1>
Instructions for creating a home lab for practicing cybersecurity operations.<br />
<h2>Prerequisites</h2>
<h3>System Requirements</h3>
We must first assure that our system can handle this HomeLab build. There are some requirements we may need to consider. 

- Host operating system must be able to support virtualization.
- 64-bit CPU (with 4+ cores) and supports Virtualization
- 16GB ram, more is better
- 300GB internal storage space

<h3>Technology Used</h3>

- Oracle VM VirtualBox (https://www.virtualbox.org/wiki/Downloads) 
- Brave (Internet Explorer alternative)

<h3>Operating Systems Used</h3>

- Kali Linux, 
- PfSense, (https://atxfiles.netgate.com/mirror/downloads/)
- Ubuntu 24.04 LTS Server, (https://ubuntu.com/download/server#manual-install-tab)
- Ubuntu Desktop, (https://ubuntu.com/download/desktop)
- Windows 10 Enterprise, 
- Windows Server 2019, 

Download the latest version of each operating system. The end result will be the same regardless of the version or year of the operating system.
