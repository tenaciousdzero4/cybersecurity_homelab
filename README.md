# cybersecurity_homelab
Instructions for creating a home lab for practicing cybersecurity operations. 
We must first assure that our system can handle this HomeLab build. There are some requirements we may need to consider. 
  • Host operating system must support virtualization (hypervisor, Etc.)
  • 12GB ram, more is better (We will be running many guest OS at once, so more resource demand on the host)
  • CPU must also support virtualization. 
  • 300GB or more internal storage
